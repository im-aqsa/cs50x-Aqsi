## 🚀 Final Project — Campus Hub

Campus Hub is a student portal developed as my CS50x final project.

📊 Student dashboard
📚 Subjects management
📝 Notes
📋 Assignments
🕐 Timetable
📈 Attendance tracking
🔐 User registration and login
🗄️ SQLite database
🎨 Responsive web interface

Python • Flask • SQLite • HTML • CSS • JavaScript
